# Classifier Comparison App

This Streamlit application allows users to compare the performance of three different classifiers on the Iris dataset: Decision Tree, K-Nearest Neighbors (KNN), and Perceptron.

## Features

- **Model Training**: Train Decision Tree, KNN, and Perceptron classifiers on the Iris dataset.
- **Performance Metrics**: View accuracy, precision, recall, and F1-score for each model.
- **Interactive Prediction**: Input sepal length and width to see predictions from each classifier.
- **Visual Decision Boundaries**: Visualize the decision boundaries of the trained models.

## Requirements

- Python 3.x
- Streamlit
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
